Introduction & Disclaimer

(Disclaimer: I am not responsible for any devices you may have broken while installing the firmware using these instructions)

Hi all, I c FrankyDoodle found a way to install custom firmware on sm-x200, sm-x205, here are the instructions

Instructions

  • 0. preparatory step we need tools (0. installed adb and fastboot 1.odin 2, Samsung USB drivers 3. custom firmware (Download firmware versions that support (arm 64) other firmware versions will not run. ) 4. official firmware interface of your version 5. download TWRP 6. and also enable USB debugging in developer settings 7. for our convenience in odin program we need to disable auto reboot (options-auto reboot ☑--- auto reboot ☐ )
  • 1. unlock the bootloader, first we need to unlock it in the developer settings (OEM unlock), then we connect the tablet to the computer and turn it off, when the screen goes out, hold the power key, VOL+ and VOL - then when you are in odin mod, press VOL+ for 7 seconds to unlock the bootloader (your data will be deleted) after unlocking the tablet will go into reboot mode, but we immediately press VOL+ and VOL - to go back to odin mod.
  • 2 we are back in odin mod, we need to flash TWRP, we flash it through AP section. After flashing the tablet must be rebooted, to do this you need to press 2 buttons power and vol- for 7-8 seconds to reboot the tablet, and immediately after the screen goes out, hold VOL+ until the tablet will not boot into TWRP.
    ( unlocking the bootloader will erase user data and if after unlocking the bootloader you go through TWRP (item above) without going through the initial setup, when you enter TWRP it will go into reboot, this is normal you just need to press vol+ when the screen goes out to return to TWRP).
  • 3. After logging into TWRP, we need to format the data section (1. From the main menu of TWRP, click "erase" - "Format Data" and write "Yes".
  • 4. After step 3, go back to TWRP main menu and select reboot --- fastboot
  • 5. After booting into fastboot we need to upload our custom firmware into the adb Fastboot folder, remembering to rename our firmware to whatever name you want, mine will be instructions.img
  • 6. From the archive with the standard firmware you need to extract the stock recovery, it is located in the AP archive, it should also be placed in the adb and fastboot folder. (the file looks like this recovery.img)
  • 7 Run the firmware, the first command is fastboot flash system instructions.img, and wait for the firmware to finish loading.
  • 8 Second command - fastboot flash recovery recovery.img
  • 9 Third command - fastboot reboot.
  • 10 After flashing the tablet may reboot 2 times and go to standard recovery, in this case you need to select data format --- yes
  • 11 and after that you will boot with custom firmware and be happy that everything works.

Rooting Instruction

This is an offshoot of the main guide, this item is optional but if someone needs root, it can be added to the above steps. To get root, we need to first download magisk.zip Magisk.apk and copy them to the SD card. (magisk.apk is needed in case it doesn't appear in the system automatically after flashing magisk.zip).

After step 7 we need to use the command 

fastboot reboot recovery

to reboot to TWRP, then in TWRP main menu we need to click on "Install" button, then on "Select Storage" button and in this list select SD card, then scroll the list and find magick.zip select it and then swipe to flash this archive and after flashing is complete go back to TWRP main menu and reboot to fastboot (reboot fastboot main menu) and continue next steps from 8-11.

Necessary Tools

  • Odin: https://odindownloader.com/download/odin3-v3-14-4
  • Samsung USB Driver: https://developer.samsung.com/android-usb-driver
  • Samsung firmware sm-x200: https://samfw.com/firmware/SM-X200/
  • Samsung firmware sm-x205: https://samfw.com/firmware/SM-X205
  • ADB Fastboot: https://developer.android.com/tools/releases/platform-tools
  • USB drivers for win7: https://developer.android.com/studio/run/win-usb
  • I got all the custom firmware here: https://xdaforums.com/t/complete-gsi-list-samsung-galaxy-tab-a8.4619197/

(be sure to download firmware for arm64 processor architecture)
